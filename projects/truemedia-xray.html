TRUEMEDIA X-RAY

Unmasking the Deepfake Era.

COMPUTER VISION CHROME SDK HEATMAPS FASTAPI

Is that really them talking? Probably not.

TrueMedia X-Ray is an infrastructure layer designed to restore trust in digital video. We're not just looking for "artifacts"—ours is a full forensic scan of the pixel stream.

[ VIZ: MAGENTA HEATMAP OVER FACE ]

The Challenge

Deepfakes are getting better. A traditional "detector" only tells you yes or no. People want to see where the manipulation is happenng. Is it the mouth? The eyes? The lighting?

The Build

I built a Chrome extension that acts as a real-time forensic lens. It taps into a backend inference engine that runs specialized face-swapping detection models. The magic is in the Overlay Heatmap—it literally paints the manipulated pixels in magenta on the fly.

We implemented a freemium model with a mock payment flow, because trust shouldn't just be free; it should be sustainable.

[ VIZ: CHROME EXTENSION HUD ]

The Impact

Restoring a baseline of reality. It's a tool for journalists, researchers, and anyone who's tired of being lied to by a 24fps MP4 file.

"Trust but verify. Then scan."
